## 🎯 Core Capabilities

- **Visual Editing**: Inline editing for static HTML generated by LLMs or tools.
- **Auto Save with Debounce**: Toggleable 1000ms debounced auto-save with instant cancellation on manual save.
- **Unsaved Protection**: Visual `🔴 Unsaved Changes` badge, `beforeunload` alert, `panel.onDidDispose` VS Code warning prompt.
- **Diagnostics**: Full error overlay with 1-click clipboard log copy.
- **Clean Save**: Temporary zoom & base tag cleanup prior to writing to disk.
