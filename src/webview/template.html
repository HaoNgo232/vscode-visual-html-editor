Visual HTML Editor Quick Guide

  • Click & Edit: Click any text inside the document in Edit Mode to edit inline.
  • Save: Press Ctrl + S or click the Save button to persist changes to disk.
  • Zoom: Use Ctrl + Scroll or Ctrl + +/- (or the Zoom dropdown) to adjust zoom.
  • Undo / Redo: Use Ctrl + Z and Ctrl + Y inside the editor.
  • Viewport: Switch between Desktop, Tablet (768px), and Mobile (375px) previews.
