# Visual HTML Editor for VS Code

Visually edit rendered HTML files directly inside VS Code and press `Ctrl + S` to instantly save changes back to your source code.

## Features
- **Visual Editing**: Edit rendered HTML text directly like in a word processor.
- **Instant Save**: Press `Ctrl + S` or click "Save Now" to overwrite the original `.html` file.
- **Context Menu Integration**: Right-click any `.html` file in VS Code or in the Editor title bar to launch.
- **Privacy & Security**: Runs 100% locally inside your VS Code instance without telemetry or external tracking.

## Usage
1. Open any `.html` file in VS Code.
2. Right-click the file in Explorer or Editor area and select **`Visual HTML Editor: Open Visual Editor`**.
3. Double-click or click any text in the preview window to edit.
4. Press `Ctrl + S` to save back to the source file.
